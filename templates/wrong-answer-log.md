# Wrong-answer log

For every practice question you **missed or guessed**, add a row. The goal is to find *patterns*, not to relive the exam.
Never copy real exam questions; this is for practice material only.

| Set | Topic / skill | Domain | Why I missed it | The rule to remember |
|-----|---------------|--------|-----------------|----------------------|
| | | | concept gap / misread / fell for a trap / guessed | |

## After each set
- Count the "why" column. **Mostly concept gaps?** Study that skill. **Mostly misreads or traps?** Read slower, check the "select N" instruction, and learn the distractor patterns.
- Note the lowest domain and spend your next session there.
- Check your score report's domain percentages the same way.
